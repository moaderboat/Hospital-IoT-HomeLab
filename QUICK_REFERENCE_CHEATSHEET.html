Attack Demo Commands
Run Dual-Target Attack (from Suricata laptop)
ssh username@192.168.50.191 cd /path/to/balloon-demo/scripts python3 attack_spoof.py --dual --pressure 0.0 --rate 0.1
What Happens:
• Attacks BOTH 192.168.50.100 (Vulnerable) AND 10.30.0.25 (Secure) at 10 Hz each
• Vulnerable Pi: Accepts fake 0.0 PSI → pump runs → pressure exceeds safe limits
• Secure Pi: Rejects fake data (sensor mismatch) → pump stays off → safe at 25 PSI
• Suricata captures all traffic → Grafana IDS Dashboard shows attacks
• Wazuh SIEM logs all rejections with forensic details
